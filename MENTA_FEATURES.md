# MENTA — MASTER FEATURE & PRODUCT ROADMAP

## PRODUCT VISION

MENTA is an AI-powered Athlete Operating System.

The goal is to bring an athlete's entire development journey into one intelligent platform:

TRAINING + PERFORMANCE + FILM + RECOVERY + SLEEP + ACADEMICS + RECRUITING + MINDSET + NUTRITION + SAFETY + AI

MENTA should feel like one premium platform instead of an athlete needing 10+ separate apps.

Core philosophy:

"Why should an athlete need 10 different apps to manage one athletic career?"

# 35. IMPORTANT DEVELOPMENT RULES

Before implementing anything:

1. Inspect the existing codebase.
2. Do NOT destroy existing functionality.
3. Do NOT rewrite working systems unnecessarily.
4. Preserve existing backend/business logic.
5. Reuse existing components where possible.
6. Keep the UI consistent.
7. Make every feature functional, not just visual.
8. Use realistic loading, empty, success, and error states.
9. Make the website responsive.
10. Test every feature after implementation.
11. Run lint.
12. Run production build.
13. Fix errors before moving to the next phase.
14. Do not fabricate integrations or data.
15. Use placeholders only when clearly labeled.
16. Never claim an API integration works unless it actually works.
17. Keep sensitive data protected.
18. Keep health/safety features educational and preparedness-focused.
19. Never present AI as a medical professional.
20. Never guarantee recruiting outcomes.
